# Ikki Development Roadmap

1. Foundation: schema, config, shared layouts, design system.
2. Storefront: homepage, collection, product detail and image gallery.
3. Commerce: cart, checkout, order transaction and WhatsApp handoff.
4. Admin: authentication, product/variant CRUD, orders and inventory.
5. CMS: navigation/submenus, page builder, homepage sections, banners and media library.
6. Operations: settings, reports, permissions and audit logs.
7. Launch: security review, InfinityFree compatibility, domain/SSL, backup/restore and end-to-end tests.
